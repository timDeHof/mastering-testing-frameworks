# Common Pitfalls to Avoid
::left::
### Jest Pitfalls

- Avoid testing implementation details
- Avoid testing constants
- Avoid testing third-party code
- Avoid testing UI directly
- Avoid testing random values
- Avoid testing time-dependent code
- Avoid testing network requests directly
- Avoid testing database operations directly

::right::
### Cypress Pitfalls

- Avoid flaky tests
- Avoid tests that depend on timing
- Avoid tests that depend on network speed
- Avoid tests that depend on user interaction
- Avoid tests that depend on browser state
- Avoid tests that depend on external services
- Avoid tests that depend on random values
- Avoid tests that depend on time
